# NCR Quest & Voice Slots: taken slots

Each quest mod that uses NCR Quest & Voice Slots needs a slot number of its
own. Two mods on the same slot break each other. The guide is
`ncr-quest-voice-slots.md`.

To take a slot:

1. Pick the lowest free number from 1 to 200.
2. Add a row with your mod's name, your name and the date.
3. Send the change as a pull request, or open an issue asking for the slot.

A slot stays taken after the mod is released. Released mods' slots are never
handed to anyone else, because saves remember which quest ran in which slot.
