# Cyberpunk 2077 - Full Gig Mods

These are the complete WolvenKit projects of my mods/gigs for Cyberpunk 2077.

I hope modders will use them to create more gigs and gameplay content.

To actually play a mod you also need RED4ext, ArchiveXL, TweakXL, Codeware and redscript. Exact versions are listed on the mod description.
